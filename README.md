# 接口流程图编辑器（Interface Flowchart Editor）

纯前端、零依赖的接口流程图编辑器——双击 `index.html` 即可使用，无需安装、无需服务器、无网络请求，数据自动保存在浏览器 localStorage 中。

**流程图的边界是各个接口（API），而非传统的「开始 / 结束」节点**：无入边的接口节点即入口（绿色徽章），无出边的接口节点即出口（蓝色徽章），边界清单随图自动统计、导出。

## 功能特性

- **四大节点类型**：接口 / 处理 / 判断 / 数据；每个大类下可把当前节点配置「存为小类」模板（含数据子段），后续拖入即用
- **接口即边界**：自动识别入口 / 出口接口节点并挂徽章，左侧面板实时统计，点击可定位
- **画布交互**：拖拽建点、四端口连线、框选、缩放平移、双击行内编辑、多选整体移动
- **属性面板**：接口节点支持自由填写的「调用方法」与路径；连线与数据节点支持 0 ~ 无限个「数据」子段，每个子段含 类型 / 限制 / 说明描述 三字段
- **自动布局**：识别「入口 → 出口」所有最短路径中**最长**的一条作为主线，排列时忽略绕回主线的逆向边（如游戏「死亡 → 重启 → 回主循环」的大回环），再按最长路径分层——主线不被拉深、重启链自然挂在外侧；边一条不删，仅不参与排列
- **多图管理**：一个文档内多个流程图，命名 / 删除 / 切换，撤销 / 重做（快照式历史）
- **导入导出**
  - 自有 `.md` 格式：人类可读、可手编、可重新导入（含坐标与数据子段）
  - Mermaid `flowchart` 粘贴导入：支持 TD/TB/BT/LR/RL 方向、`-->` / `-.->` / `==>` 箭头、`|标签|`、链式连写、先引用后定义、常见形状映射（菱形→判断、圆柱→数据等）

## 快速开始

直接双击 `index.html`（纯静态页面，`file://` 下即可运行），或：

```bash
npx http-server .    # 或任意静态文件服务器
```

## 数据格式（.md）

```flow
n1[API|用户注册|POST /api/auth/register]
n2[PROC|验证参数]
n3{DECISION|邮箱已注册?}
n1 --> n2
n2 --> n3
n3 -->|是| n4[API|返回错误|GET /api/error]
n3 -.->|否| n5[DATA|保存记录]
  data: string | max 64 | 错误描述
```

- **节点**：`id[TYPE|名称|接口路径|说明]`，判断节点用 `id{...}`；TYPE = `API` / `PROC` / `DECISION` / `DATA`
- **边**：`a --> b`、`a -->|标签| b`、`a -.-> b`（虚线）；节点可内联在边两端
- **数据子段**：`data: 类型 | 限制 | 说明描述`，缩进行归属于上一行实体（节点或边）
- **坐标**：导出不包含坐标（文件干净、可 diff），导入后自动布局；手写时可加 `@(x,y)` 指定位置
